# ⚡ PEM Electrolyzer Modelling | MATLAB & Simulink

A dynamic equivalent electrical circuit model of a Proton Exchange Membrane (PEM) Electrolyzer for analysing its electrical performance and transient behaviour.

- ⚙️ Developed an equivalent electrical circuit using a voltage source, ohmic resistance and two RC branches.
- 📐 Derived static and dynamic mathematical models to represent electrolyzer characteristics.
- 🔄 Analysed transient voltage response using fast and slow time constants.
- 💻 Implemented the complete electrical model in MATLAB/Simulink.
- 📊 Performed equivalent circuit parameter identification using the Least Squares method.
- ⚡ Investigated current-step responses and dynamic polarization characteristics.
- 📈 Evaluated stack voltage, power consumption and energy efficiency.
- 💧 Estimated hydrogen production using Faraday's law.
- 🌡️ Analysed temperature variations under different operating conditions.
- 🌱 Explored the potential integration of PEM electrolyzers with renewable energy systems.

**Tools:** MATLAB | Simulink | Electrical Circuit Modelling | Parameter Estimation
